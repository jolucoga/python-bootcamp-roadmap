# 🐍 Python 3 Complete Bootcamp — Code & Projects

![IDE](https://img.shields.io/badge/IDE-VS%20Code-blueviolet.svg)

Repositorio de seguimiento y documentación del curso **Complete Python 3 Bootcamp** (Pierian Data). 

A diferencia del formato tradicional basado en Jupyter Notebooks, todo el código de este repositorio está refactorizado en **scripts modulares de Python (`.py`)**, aplicando estándares profesionales de la industria como *Type Hints*, *Docstrings*, separación de responsabilidades y ejecución mediante terminal con `VS Code`.
